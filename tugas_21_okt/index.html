Pertanyaan Analisis

1. Mengapa array cocok untuk menyimpan data banyak siswa?

Karena array dapat menyimpan banyak data dalam satu variabel.

2. Apa perbedaan filter() dan map()?

filter() memilih data sesuai kondisi, sedangkan map() mengolah setiap data menjadi array baru.

3. Bagaimana menangani siswa yang belum memiliki nilai?

Nilai kosong harus diperiksa agar tidak ikut dihitung dalam rata-rata dan status kelulusannya belum ditentukan.
